# v0.10.0

## Highlights

v0.10.0 adds a human-optional reviewed-source gate and replaces one-segment-per-request contextual translation with auditable contextual micro-batching.

### Reviewed source Markdown

After chapter recovery, Vision evidence and any manual structure decisions are complete, the pipeline now performs conservative post-structure cross-page prose stitching and generates:

`source_review.md`

The file is a readable source-language electronic edition with:
- Markdown heading hierarchy;
- visible source page/page-span markers;
- stable hidden `BOOK_SEGMENT` comments for round-trip identity.

Before glossary or translation, the workflow requires a choice:

```bash
# Pause and manually review/correct source_review.md
python3 new_book.py source-review --project <PROJECT_DIR> --mode manual

# After editing:
python3 new_book.py apply-source-review --project <PROJECT_DIR>

# Or approve the generated source and continue automatically
python3 new_book.py source-review --project <PROJECT_DIR> --mode auto
```

Manual import updates canonical segment text/source hashes, heading text/levels/parents and writes `work/reviewed_structure.json`. The chapter analyzer keeps ownership of the baseline structure. Approval binds the raw source, baseline structure, reviewed structure, Markdown and canonical segments; later Markdown edits fail closed until reapplied.

Windows GUI asks the same Yes/No question after structure/Vision processing. Choosing manual review opens `source_review.md` and waits for the user to press “应用原文MD”.

### Post-structure cross-page merging

OCR prose fragments are stitched only when:
- both are paragraphs;
- they have the same structural parent and zone;
- pages are consecutive;
- the preceding fragment does not end a sentence.

Hyphenated page breaks join without an inserted space. Page start/end and contributing OCR block provenance remain attached to the canonical segment and are visible as page spans in the reviewed Markdown.

### Contextual micro-batching

Segments remain the persistence, cache invalidation, QA and EPUB DOM-writeback atom. API requests can now carry multiple consecutive targets from the same chapter.

Default new-project settings:
- up to 4 ordinary targets per request;
- up to 6000 source characters;
- one external previous and next segment for context;
- 300-character previous-translation continuation tail;
- table/table-cell/attribute/footnote/caption/reference-like high-risk items default to singleton batches;
- up to 4 independent chapter lanes;
- proactive fixed RPM pacing disabled by default; bounded provider 429/network retry remains active;
- translation temperature 0.1;
- thinking disabled.

The wire protocol uses compact local numeric indexes instead of returning long stable segment IDs.

### Partial salvage and recursive fallback

A micro-batch is not an all-or-nothing retry unit:
- independently valid translations are committed immediately;
- missing or structurally invalid targets are isolated;
- unresolved groups are recursively split;
- singleton targets receive bounded parse retries.

This avoids retransmitting and paying output cost again for valid siblings when only one target fails.

### Prompt/token efficiency

Prompt-facing chapter briefs now contain only semantic translation context. Machine-only brief hashes, page ranges and segment counts remain in provenance/cache metadata instead of being resent to the model.

Preflight uses the real batch planner and reports:
- estimated remaining requests/batches;
- average/max planned batch size;
- singleton batch count;
- remaining translatable characters.

Usage records preserve actual provider completion request counts, including recursive fallback calls.

### Automatic terminology

Once the reviewed-source gate is approved, the existing automatic DeepSeek terminology flow continues. Manual reviewed-source import and auto approval both proceed to automatic glossary review in the normal workflow.

### Windows / Skill / Coding Agent

- Windows GUI includes “打开原文MD” and “应用原文MD”.
- The installable Skill must explicitly ask whether the user wants manual reviewed-source confirmation.
- If the user chooses manual review, the Skill must stop until the user says the file is ready.
- Coding Agent instructions and generated RUNBOOKs use the same gate.
- Frozen Windows smoke exercises PDF/Vision → reviewed source → automatic terminology → contextual micro-batch translation.
